# Contributing to PromptBox

Thanks for taking the time to contribute.

## Ways to help

- Report a bug by opening an issue
- Suggest a feature by opening an issue
- Improve translations or documentation
- Open a pull request with a small, focused change

## Development

PromptBox has no dependencies or build step. After changing files, run the tests:

```bash
npm test
```

Keep changes focused. When you touch `js/logic.js`, add or update a unit test in `test/logic.test.js`.

## Pull request checklist

- Run `npm test` locally
- Describe what changed and why
- Add a screenshot for user-visible UI changes when practical
- Keep the title short and clear
